# Hardware

Open `kicad/neuronic.kicad_pro`. Read `validation/STATUS.md` and
`../docs/START_HERE.md` first.

`design.json` is generated by `tools/generate_hardware.py` and describes the
component/net/placement checkpoint. It is not a substitute for the actual
KiCad schematic or DRC. `bom/bom-review.csv` lists candidate parts and unresolved
MPNs; it is not a purchase-ready BOM.

KiCad source, script and review docs belong in Git. Fabrication files should
only be exported for reviewed, tagged hardware revisions.
