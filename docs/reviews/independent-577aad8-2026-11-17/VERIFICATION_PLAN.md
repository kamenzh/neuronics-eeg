# Ordered verification plan — no person connected

These are proposed tests, **not completed measurements**. Use a dummy-electrode fixture and appropriate current limiting. Archive failures as well as passes. Existing `docs/BENCH_TEST_PLAN.md` and `docs/POWER_HARNESS_A0_3.md` are useful starting procedures; this plan adds explicit issue closure and acceptance evidence.

| Order | Task / linked findings | Evidence needed to pass or decide the next step |
| --- | --- | --- |
| 1 | One P1 8R003661901F sample with actual Sino-k lead; exact J11/SW1 headers (**IR-06**) | Record manufacturer/model, measured dimensions, mating and continuity. Verify retention and removal without unsupported board bending. Establish finished-hole/slot tolerances with the selected shop. If uncertain, use an inexpensive fit coupon before a full PCB batch. |
| 2 | Revision-locked manufacturing package (**IR-07/10**) | Named 4-layer stack/thickness/copper/finish, board orientation and PTH/NPTH files; 20 plated slots explicitly recognized; fine-pitch mask preview; archived hashes and fabricator acceptance. Update the outdated BOM prose separately. No mass order is justified by this report alone. |
| 3 | Assembly and unpowered inspection | Board revision/serial; microscope photos of U1/U4/U5; no bridges or lifted pins; D10 cathode and C24 positive verified; every connector-to-pin continuity; no unintended rail short. Account for capacitor charging in resistance measurements. Check real J11 cable pin11=host3V3 and pin12=GPIO6, not the A0.2 wiring. |
| 4 | First power and startup (**IR-02/03**) | Current-limited source over the declared pack range; actual limit chosen from the budget and inrush; AVDD/DVDD at U1 within operating and selected-regulator limits; no excess heat. High-impedance VCAP1/VREFP traces through cold start, warm restart and shutdown. Honor both power-on timing and VCAP1>1.1V before the documented reset/configuration. Establish stable reference before accepting data. |
| 5 | Supply-state matrix (**IR-02**) | Host-only, AFE-only, both orders, host reset, disconnected supplies, slow discharge, low-pack/radio bursts and independent analog dropout. Capture rail and GPIO voltages/current. Do not count records from invalid states as valid samples. Verify recovery through reset/configuration, not merely that the program resumes printing numbers. |
| 6 | Minimal firmware + raw recorder (**IR-08**) | Pinned reproducible build and firmware commit; correct native GPIOs; IF_EN default off; register dump/readback with masks; measured mode1/1 MHz timing and DRDY. Test sign extension at `0x000000`, `0x7fffff`, `0x800000`, `0xffffff`, status framing, channel order, sequence-counter wrap, truncated/corrupt packets and restart/session handling. These tests are implementation work for the next stage, not claimed here. |
| 7 | Internal-test acquisition | Bias/lead-off disabled. Correct all-eight-channel test waveform frequency and scale using the documented register formula, oscillator tolerance and independently checked calibration. Resolve the datasheet amplitude-table discrepancy if observed. Run at least ten minutes; preserve raw frames and device/host timestamps. Require no unexplained loss, duplicate, reordering or overrun; compare physical DRDY counts/timing where possible. ISR counters alone can miss unserviced edges. |
| 8 | Internal short and external dummy source (**IR-03/04/08**) | Record at least 60 s per condition. Compare internal short with external balanced fixture at valid ~2.5V common mode. Verify 10 Hz differential signals of 20/50/100 µV with a characterized attenuator/calibrator. Check gain, polarity, channel identity, crosstalk and full external contact path. Initial development goal: ≤1 µV RMS over explicitly documented 0.5–40 Hz bandwidth; keep raw unfiltered recordings and processing code. |
| 9 | CMRR, impedance, cable and offset sweep (**IR-04**) | Apply low-energy 50/60 Hz common-mode signal, initially 10 mV then 100 mV if linear. Test equal impedances, +5k and +50k imbalance, and separately 0.5/1/5 nF cable loads. Measure all channels, no notch. Initial goal ≥60 dB with balanced fixture; characterize unequal cases without pretending they must meet the same target. Sweep differential DC offsets within safe common-mode limits at gains 6/12/24 and record clipping/recovery. |
| 10 | Bias closed loop (**IR-05**) | First approve exact source/load network and sense mask. Then record BIASOUT/common mode across load extremes and contact open/reconnect/overload. No sustained oscillation or unexplained long saturation; define an acceptable recovery time for the intended experiment before claiming a pass. Keep bias disabled if a safe, bounded bench fixture/model is unavailable. |
| 11 | Edge, radio and ground behavior (**IR-09/02**) | Compare SCLK/START at buffer and ADC using short-ground/appropriate probes; receiver overshoot/undershoot and setup/hold inside device limits. Repeat raw noise/test captures radio off/on and while streaming. If a failure is found, change one cause at a time and retain before/after data. |
| 12 | Bounded analog injection/reverse current (**IR-02/01**) | Design the fault fixture before energizing it; first calculate/test a resistor-and-diode dummy network. Observe rail rise and reverse current for powered/unpowered input stimulus without exceeding device stress. Do not connect raw battery/mains voltage to an ADS input as an informal “protection test.” Verify intended protection changes with a qualified reviewer if higher-energy fault testing is needed. |
| 13 | Body-use decision (**IR-01**) | Separate qualified review of entire final enclosure, harness, communication and charging arrangement; every electrode-current path in normal and credible single faults; measured leakage/insulation/protection evidence using suitable methods. No person is the test load for steps 1–12. Bench acquisition success does not close this step. |

For each run retain: board serial/revision; firmware and host commits; instrument model/calibration status and probe loading; exact fixture schematic and component values; power source/current limit/temperature; cable lengths/radio state; register dump; sample rate/gain/reference; raw file hashes; analysis/filter settings; measured result and pass/fail rationale; reviewer/date. Distinguish nominal design goals from manufacturer limits and from the eventual system-safety criteria.

A practical economical sequence is **sample/coupon → a small bench PCB batch → instrumented bring-up → targeted changes justified by measurements**. The cost of a wholesale redesign or complete shopping list is not justified by the current evidence alone.
